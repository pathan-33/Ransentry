RANSENTRY

Ransomware Early Warning System · See Threats. Stop Damage. Stay Secure.

This utility focuses on a Ransomware Early Warning System to identify the initial stages of a ransomware attack (e.g., encryption, defense evasion). It uses a dynamic risk scoring model with time decay to track suspicious activities on a simulated endpoint and visualize the threat level in real-time using an embedded Matplotlib graph.

Core Features

Heuristic Risk Model Uses a defined set of actions (e.g., Encrypting_Operation, Delete_Backups) assigned to high-risk scores.
Time-Decay Engine Individual risk events expire after a 10-second window, simulating that suspicion fades if anomalous activity does not continue.
Real-time Visualization Embeds a Matplotlib graph that plots the accumulated risk score over time.
Attack Simulation Modes Normal (low, sporadic risk) and Malicious (high-risk sequence typical of ransomware execution).
Critical Alerts Dynamic indicator shows SAFE, HIGH RISK, or RANSOMWARE ATTACK once the score exceeds the threshold (150).
Color-Coded Logging Activity log highlights severity of each simulated event in real time.

Advanced System Modules

Honeypot Deception Environment Deploys monitored decoy assets in honeypot_files/ watching for unauthorized access or modification via Python watchdog.
Cryptographic Hash-Chain Log SHA-256 block chain logging providing tamper-evident audit trails and cryptographic integrity verification.
Live Threat Intelligence Feed Fetches real-time URLhaus ransomware indicators and dynamically adjusts alert sensitivity multipliers.
AI Adaptive Pattern Recognition Random Forest Classifier evaluating operational sequences over rolling 20-action windows.
Interactive SOC Incident Dispatcher Configurable P1/P2 alert dispatcher sending structured JSON payloads to Tier-2 SOC response teams.
Dynamic 3-Tier Security Quiz Easy, Medium, and Hard interactive quizzes with instant Red/Green option feedback and live scoring.

Behavioral Risk Heuristics

Behavioral Action Risk Score Description
Security_Disable 100 Critical event (e.g., disabling anti-virus).
Delete_Backups 75 Highly malicious (attempting to prevent recovery).
Encrypting_Operation 50 Strong indication of file modification/locking.
File_Rename_Op 25 Suspicious file operation pattern.
Mass_File_Read 10 Precursor to encryption (reconnaissance/copy).
Normal_Modify 2 Standard user file editing/saving.
Normal_Access 1 Standard user file viewing.
Defense Policy: RANSOMWARE THRESHOLD is set to 150. Time window for risk decay is 10 seconds.

How to Operate

  1. Start the Application — Run python Ransomware.py.
  2. Start Simulation (Normal) — Observe low, fluctuating risk scores as benign activity occurs and decays.
  3. Start Simulation (Malicious) — The log shows high-risk events; score spikes and the indicator changes to WARNING/DANGER.
  4. Observe Decay — Stop the simulation and watch the graph drop back toward zero as events expire.
  5. Analyze Results — Use the real-time metrics and graph to review the attack lifecycle and defense efficacy.
